# Chrome Web Store Privacy Practices

## Single purpose

CleanTab removes known tracking parameters from URLs and safely suspends browser tabs using local browser controls.

## Data collection disclosure

CleanTab does not collect or transmit user data. URLs and form-dirty signals are processed locally to provide the user-facing features. No data is sold, shared, used for advertising, used for credit decisions, or read by humans.

## Limited use certification

CleanTab's use of browser permissions is limited to its prominently described URL-cleaning and tab-suspension features. It does not transfer data to third parties or use data for unrelated purposes.

## Remote code

CleanTab does not use remote code, external scripts, WebAssembly downloads, `eval`, or remotely hosted executable resources.

## Authentication and payments

CleanTab has no authentication, account, payment, subscription, or in-extension purchase.
