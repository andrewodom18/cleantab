# Chrome Web Store Listing

## Name

CleanTab

## Summary

Clean tracking from URLs and safely suspend tabs. Private, local, and lightweight.

## Category

Tools

## Detailed description

CleanTab gives you two focused browser tools without collecting your browsing activity.

- Remove common marketing trackers from URLs before sharing them.
- Preview every cleaned URL and see which parameter names were removed.
- Clean page, link, or selected URLs from the right-click menu.
- Optionally clean copied URLs automatically.
- Suspend the current tab or other eligible tabs without closing them.
- Optionally suspend inactive tabs after a time you choose.
- Always protect active, pinned, audible, excluded, browser-internal, and known unsaved-form tabs.
- Customize domain exclusions and URL parameter rules.
- Use system, light, or dark appearance.

CleanTab runs entirely in Chrome. It has no account, server, analytics, advertising, telemetry, or persistent URL history. Automatic features request optional website access only when you enable them.
